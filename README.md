# House-Price-Prediction
Its my first project in machine learning. It compares the price of houses considering different factors using linear regression model.

House Price Prediction
Description
This project predicts house prices based on location, size, and other relevant features using a Linear Regression model. It uses an 80-20 train-test split and also applies Lasso and Ridge regression techniques for improved accuracy. The model is trained and evaluated on a dataset containing various house attributes, making it a reliable tool for estimating house prices.

Features
Preprocesses the dataset by handling missing values, removing duplicates, and encoding categorical variables.
Detects and removes outliers from the dataset using the Interquartile Range (IQR) method.
Applies Linear Regression for initial predictions.
Implements Lasso and Ridge regression techniques for better model performance and regularization.
Evaluates model accuracy using Mean Absolute Error (MAE).
Installation
Clone this repository.
Open the project in Google Colab.
Upload the provided CSV file (HousePricePrediction.xlsx - Sheet1.csv) in Colab to see the output.
Usage
Open Google Colab: Upload the dataset file when prompted.
Run the Cells: Execute the cells sequentially to:
Preprocess the data.
Train the model using Linear Regression, Lasso, and Ridge techniques.
Evaluate the model's performance using Mean Absolute Error (MAE).
View Predictions: The model will display the first 5 predictions and the corresponding actual values.
